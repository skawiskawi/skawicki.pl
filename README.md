# skawiskawi.pl

Minimal personal link hub with live Spotify status and interactive background.

## Features

- Spotify integration: Displays currently playing or recently played track with dynamic color extraction from album art.
- Interactive canvas background: Gradient blobs reacting to cursor and touch movement with strobe light flashes.
- 3D tilt interaction on link cards.
- Zero dependencies: Pure HTML, CSS, and vanilla JavaScript in a single index.html file.
